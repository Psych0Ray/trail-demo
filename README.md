# Trail, working demo

A clickable demo of Trail, an Android layer that checks videos and photos while they play.
Static site: open `index.html`, or deploy the folder as is.

## Deploy to Vercel
1. Install Node.js if you don't have it.
2. In this folder, run: `npx vercel --prod`
3. Log in when asked. Accept the defaults (no build command, output is this folder).

Or push this folder to a GitHub repo and import it at vercel.com/new (Framework preset: Other).

## Files
- `index.html` the whole demo (markup, styles, script)
- `assets/` photos exported from the Figma file
- `fonts/` Figtree (SIL Open Font License, see OFL.txt)
